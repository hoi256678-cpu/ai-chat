# 위기 감지 평가 문장 (64개)

위기 감지가 얼마나 놓치고(미탐) 얼마나 잘못 울리는지(오탐) 재려고 만든 문장 목록입니다. **실제 사용자 메시지가 아니라 측정을 위해 직접 만든 문장**이고, 문장마다 "사람이 읽었을 때 위기 신호로 봐야 하는가"라는 정답을 붙였습니다.

- 원본 데이터: [`lib/crisisEval.data.ts`](../lib/crisisEval.data.ts)
- 측정 테스트: [`lib/crisisDetection.eval.test.ts`](../lib/crisisDetection.eval.test.ts) (`npm test`로 함께 실행)
- 만든 과정: 2026-11-05에 47문장으로 시작했고, 2026-11-20에 키워드를 넓히면서 위기 표현 7개와 함정 문장 5개를, 형태소 작업에서 합성어 5개를 더해 64문장이 됐습니다. 자세한 과정은 [학습 기록](study/algorithm-study-log.md) §11, §12에 있습니다.

## 표 읽는 법

| 칸 | 뜻 |
|---|---|
| 정답 | 사람이 판단한 위기 여부 |
| 1차 판정 (키워드) | `crisisLevel()` 결과. `direct` = 원문에 위기 표현이 그대로 있음, `normalized` = 띄어쓰기·기호를 지워야 걸림, `none` = 안 걸림 |
| 형태소 반영 후 | `direct` 중 "자살"·"자해"가 들어 있으면 Kiwi로 다시 본 결과(`refineWithMorphemes()`). 합성어면 `normalized`로 바뀜 |
| 처리 | 실제 화면: **항상 안내** = 109 안내 띠를 코드가 무조건 붙임, **AI 판단** = Gemini가 위기라고 판단할 때만 붙임, **없음** = 안내 없음 |

아래 표는 지금 저장소의 코드와 실제 Kiwi 모델로 문장마다 돌려서 만든 결과입니다(2026-11-20). "AI 판단" 문장의 최종 결과는 Gemini 답변에 따라 달라서 표에 넣지 않았습니다.

## 요약

| 종류 | 개수 | 결과 |
|---|---:|---|
| 그대로 쓴 위기 표현 | 15 | 15개 모두 항상 안내 (**미탐 0**) |
| 쪼갠 위기 표현 | 8 | 8개 모두 AI 판단으로 넘어감 (측정에서 Gemini가 8개 모두 위기로 판단) |

| 일상 문장 | 12 | 하나도 안 걸림 (**오탐 0**) |
| 돌려 말하기 | 8 | 하나도 못 잡음 (**알려진 한계**, 다음 목표: 단계별 기준선) |
