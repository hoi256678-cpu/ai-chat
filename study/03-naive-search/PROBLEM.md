# 03. 숨은 금지어 찾기 (단순한 방법)

시간 제한: 2초 | 메모리 제한: 1536 MB

## 문제

금지어 N개와 메시지 하나가 주어진다.
메시지 **안에 등장하는 금지어의 총 횟수**를 구하라.

- 금지어끼리 겹치거나 포함되어도 **각각 센다.**
- 같은 금지어가 여러 위치에 나오면 **위치마다 센다.**

이번에는 01-trie의 트라이를 이용해서 **"메시지의 각 위치에서 트라이를 따라 내려가 보는"** 단순한 방법으로 푼다.
(다음 문제에서 같은 문제를 Aho-Corasick으로 다시 풀고 속도를 비교한다.)

## 입력

- 첫째 줄: N (1 ≤ N ≤ 1,000)
- 다음 N줄: 금지어 하나씩. 서로 다르다. 길이 1 이상 100 이하.
- 마지막 줄: 메시지. 길이 1 이상 100,000 이하.
- 모든 문자열은 **알파벳 소문자**로만 이루어져 있다.

## 출력

메시지 안에 등장하는 금지어의 총 횟수를 출력한다.

## 예제 입력 1

```
4
he
she
his
hers
ushers
```

## 예제 출력 1

```
3
```

`she`(1~3), `he`(2~3), `hers`(2~5).

## 예제 입력 2

```
2
a
aa
aaaa
```

## 예제 출력 2

```
7
```

`a`가 4번(위치 0, 1, 2, 3), `aa`가 3번(0~1, 1~2, 2~3).

## 생각해 볼 것

1. 메시지 버퍼 크기는? 이번엔 100,000자다. 이 배열을 `main` 안의 지역 변수로 둬도 될까?
2. `search`를 그대로 쓸 수는 없다. 어떤 함수를 새로 만들어야 할까? (매개변수: 트라이, 메시지, 시작 위치)
3. 정답이 `int` 범위를 넘을 수 있을까? (최악: 메시지 100,000자, 금지어가 a, aa, aaa, … 100개)
