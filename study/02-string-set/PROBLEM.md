# 02. 금지어 검사기

시간 제한: 2초 | 메모리 제한: 1536 MB

## 문제

채팅 서비스에 **금지어 목록 S**가 N개 등록되어 있다.
사용자가 보낸 메시지 M개가 주어질 때, 메시지 **전체가 금지어 목록의 단어 하나와 정확히 같은** 메시지가 몇 개인지 구하라.

- 접두사만 같은 경우는 같은 것이 아니다. (목록에 `cart`만 있을 때 메시지 `car`는 해당 없음)
- 같은 메시지가 여러 번 나오면 나올 때마다 센다.

## 입력

- 첫째 줄: N, M (1 ≤ N ≤ 10,000, 1 ≤ M ≤ 10,000)
- 다음 N줄: 금지어 하나씩. 서로 다르다.
- 다음 M줄: 메시지 하나씩. 중복될 수 있다.
- 모든 문자열은 **알파벳 소문자**로만 이루어져 있고, 길이는 **1 이상 500 이하**이다.

## 출력

첫째 줄에 금지어와 정확히 같은 메시지의 개수를 출력한다.

## 예제 입력 1

```
4 6
cat
car
cart
dog
ca
cat
cars
dog
cat
do
```

## 예제 출력 1

```
3
```

`cat` 2번, `dog` 1번. `ca`, `do`는 접두사일 뿐이고 `cars`는 목록에 없다.

## 생각해 볼 것

1. 버퍼 크기 `char buf[???]`는 얼마여야 하나? (`'\0'` 자리 포함)
2. 최악의 경우 노드는 몇 개 생기나? 노드 하나 ≈ 216바이트일 때 메모리 제한 안에 들어오나?
3. 입력이 클 때 `scanf("%s", buf)` 한 번에 몇 글자를 읽나?
