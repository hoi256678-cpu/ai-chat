# 04. 실패 링크 만들기 (BFS)

시간 제한: 1초 | 메모리 제한: 256 MB

## 문제

금지어 N개로 트라이를 만들고, 트라이의 **모든 노드에 실패 링크**를 단다.
그다음 질문 Q개에 답한다. 질문은 트라이에 있는 노드 하나(root에서 그 노드까지의 문자열)이고,
그 노드의 **실패 링크가 가리키는 노드의 문자열 길이**를 출력한다. root를 가리키면 0이다.

> 실패 링크: 노드가 나타내는 문자열의 꼬리(앞 글자를 떼어 낸 뒷부분) 중,
> root에서 출발하는 경로로 트라이에 있는 가장 긴 것. 자기 자신은 빼고, 없으면 root.

실패 링크가 가리키는 문자열은 항상 질문 문자열의 꼬리라서, **길이만 알면 어떤 노드인지 하나로 정해진다.**
(예: `"she"`의 실패 링크가 길이 2라면 그건 `"he"`다.)

실패 링크는 **BFS로, 부모의 실패 링크를 이용해서** 만든다. 노드마다 꼬리를 하나씩 떼어 root부터 다시 찾는 방법은 쓰지 않는다.

## 입력

- 첫째 줄: N Q (1 ≤ N ≤ 1,000, 1 ≤ Q ≤ 100,000)
- 다음 N줄: 금지어 하나씩. 서로 다르다. 길이 1 이상 100 이하.
- 다음 Q줄: 질문 하나씩. 항상 트라이에 있는 노드의 문자열이다 (어떤 금지어의 앞부분, 길이 1 이상).
- 모든 문자열은 **알파벳 소문자**로만 이루어져 있다.

## 출력

질문마다 한 줄에 실패 링크가 가리키는 노드의 문자열 길이를 출력한다.

## 예제 입력 1

```
4 9
he
she
his
hers
h
s
he
hi
sh
her
his
she
hers
```

## 예제 출력 1

```
0
0
0
0
1
0
1
2
1
```

지난번에 손으로 그린 9개다. `sh → h`(1), `his → s`(1), `she → he`(2), `hers → s`(1), 나머지는 root(0).

## 예제 입력 2

```
3 4
abcd
bcx
cd
ab
bc
abc
abcd
```

## 예제 출력 2

```
1
1
2
2
```

DFS로 a 가지부터 만들면 `"abcd"`를 처리할 때 `"bc"`의 실패 링크가 아직 없어서 틀리거나 죽는 예제다. 정답은 `abcd → cd`(2).

## 생각해 볼 것

1. 출력해야 하는 건 실패 링크 노드의 **문자열 길이**다. 노드 구조체에 무엇을 더 저장해 두면 될까?
2. BFS에는 큐가 필요하다. C에는 큐가 없다. 배열로 만들 때 크기는 얼마면 충분할까? (노드는 최대 몇 개?)
3. root의 자식(깊이 1)의 실패 링크는 무엇인가? 이 노드들도 일반 규칙("부모의 실패 링크를 따라간다")으로 처리할 수 있을까, 아니면 따로 처리해야 할까?
4. `f = f->fail`을 반복하다가 root까지 왔는데도 그 글자의 간선이 없으면 어떻게 끝내야 할까? 무한 루프가 생기지 않을까?
